Review fixes, 2026-10-04 UTC

CURRENT REVISION
- Replaced the AArch64 interpreter's code-cache far_jump with address
  materialization (lea) and an indirect branch (br) to the libjvm C++ leaf.
  This handles native targets independently of ReservedCodeCacheSize.
- Added per-source clang deprecated-declarations suppression for the bridge
  and unmodified vendor unit; libc++ headers may reference allocation functions
  deprecated by HotSpot. Other HotSpot sources retain their warning policy.
- Included globals_extension.hpp explicitly for FLAG_IS_DEFAULT; the minimal
  VM's precompiled header does not provide that macro.
- Latin-1 to UTF-8 now reserves 2 * len bytes before conversion. Insufficient
  capacity returns -1 before any write instead of reporting a truncated prefix.
- Benchmark resume verifies the selected benchmark/size Cartesian product,
  rejecting missing, extra and duplicate results; the manifest records the
  resolved benchmark names as well as the filter.
- Added explicit 48 MB code-cache interpreter/tiered runs and capacity canaries
  to the jtreg contract.
