The [preceding review](../final-20261022/SOURCE-REVIEW.md) applies to unchanged native kernels, byte-set scanners, publication, mixed-coder arithmetic and bounds. This revision replaces its seven-argument UTF16 dispatch with the original six-argument unresolved entry. A tier value no longer travels through the public long-input path, and no resolved hint is allowed to suppress the checked entry's physical validation.

For UTF16 C1 long needles with exactly one or two candidate positions, the existing reverse-search admission remains authoritative. Where that admission selects Java fallback, the checked entry can instead verify the candidates through the existing native equality bridge. A first-code-unit filter rejects obvious misses before entering the outlined helper. The helper makes at most two equality calls, each bounded by `MAX_BYTES` (64 KiB), and handles `FALLBACK` using the existing Java reverse loop. Larger needles retain the prior fallback. Physical source and target ends have been checked before this helper; immutable array lengths and the 0/1 candidate restriction keep both offsets valid. No new native entry, unsafe access, compiler intrinsic or platform capability is introduced. Existing eligible reverse searches preserve their route.

For the dense serial C2 Latin1 fallback, a complete target array permits deriving the target length and bounded source prefix inside the separately compiled scalar method. The already-tested rightmost position is excluded by subtracting one from the searched prefix, rather than from an unchecked array offset. The minimum source prefix in this branch is 256 bytes and target width is at most 128, so a complete remaining candidate exists. Every byte access remains a Java checked array access. Internal callers that use a target-array prefix retain the existing generic checked helper. The scalar loop otherwise preserves the original reverse-search algorithm.

Tests add an independent char-unit oracle for String, StringBuilder and StringBuffer delegation, right/left hits, misses, 127/128/129 and 32768/32769-unit equality-window boundaries, unused-capacity poisoning, and full/partial dense Latin1 prefixes with 63/64/65/66-unit needles. The limited-AVX test descriptor now runs both C1 and C2 with AVX disabled and AVX2 selected. The prefix microbenchmark validates its expected result with an independent bounded scalar oracle.

PR63's eight commits remain preserved in history. The allocation-header integration correction and per-file MSVC optimization setting remain present. Macro checks prove `/O2` for release/fastdebug and `/Od` for slowdebug; actual native release compile commands are verified separately. This is not a claim of three MSVC native builds.

Remaining performance costs and all observed losses are part of the results, not correctness exceptions. Earlier source results and exploratory patches remain labelled by their own identity and are not substituted for complete-image qualification of this revision.
