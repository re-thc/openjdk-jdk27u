# Assessment of b19af25c

Candidate `b19af25c4ccac240e017ca15bfbfc955d4798aa4` incorporates PR63, but is superseded by the [final-source assessment](../final-20261022/RESULTS.md). Its complete measurements found a dense serial reverse-search regression introduced by scalar inlining, and a remaining NEON C1 short-UTF16 dispatch cost. Follow-on G/H experiments support isolating the bulk scalar C2 loop and selecting the existing short C1 fallback earlier. Their results are diagnostic evidence, not qualification of a later source.

All **184 case groups, 2,944 original JMH files and 14,720 samples** are retained in [the complete archive](b19-complete-measurements.tar.gz), with [archive/member hashes](b19-complete-measurements.receipt.json). Every raw file was audited. The [complete comparison table](b19-COMPARISONS.md) retains all controls and paired ranges; [the losses table](b19-LOSSES.md) retains the union of paired, control-median and pooled-mean losses. There are 133 union-loss rows; 76 paired losses against the independent original. This deliberately loss-focused selection is not a population estimate.

The independent original is `416d7db3ec3cf03d0e4b05f919dce6aa9f9b5eda`. Local prior is PR63 `3c06040bad5a43930dbbcbd463156e885473badf`; native prior is PR4 `7048d6f2c74e25737850789812da063900ec18c0`, which lacks PR63. Candidate enabled and disabled use the same complete image. Each case has four balanced rotating rounds, ordinary single-fork JMH, three 300 ms warmups and five 300 ms samples. Ratios are medians of paired round-median ratios; minimum/maximum are observed spread, not confidence intervals. No noise gate excludes losses. Disabled is not an independent baseline.

Selected bulk operations improve greatly, while early scan exits and several short verifiers lose. Local serial C1 minimum-overlap search recovered to a paired 1.118x original/candidate ratio; serial C1 Latin-1 equality improved 35.37x. C2 isBlank with a non-whitespace character at offset 40 remained slower: 10.50 ns original versus 18.39 ns candidate, paired ratio 0.573. Dense serial C2 65-byte near-matches regressed against the prior; the follow-on isolation experiment recovered roughly 13–17%. See all rows and ranges before drawing conclusions.

Ordinary complete-process comparisons use eight balanced rounds with default tiering and CDS. Original/candidate paired ratios were startup 1.0298 [0.9801, 1.2836], javac 1.0042 [0.8809, 1.0682], and source indexing 1.0016 [0.9204, 1.2083]. These do not establish an application speedup. Raw stdout/stderr, commands, checksums and class/image invariance checks are in the archive's `process` directory.

The exact-head local String/intrinsic suite passed 125 descriptions with five skips. Native paired build/targeted validation jobs completed on NEON and MSVC. Ordinary CI passed both Linux x64 builds and all 12 x64 test groups, then failed the ARM release test-library build because `libStringZillaKernelsTest.c` omitted `<stdlib.h>` for malloc/free; the ARM debug sibling was cancelled. A later candidate supplies the explicit include and adds native ARM contract/sanitizer validation. This run is not a complete green CI qualification.
