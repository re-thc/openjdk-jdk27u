Updating zlib-ng in OpenJDK

Sources: zlib-ng/ (upstream plus maintained raw-inflate CRC patch);
stock zlib 1.3.2 remains the fallback. See make/data/zlib-ng/README.md
for the required patch/probe, pinned replay checksums and rebase procedure.
Version: 2.3.90
Revision: 49323f2af98b92fccf03cfc62ea2cb5591a3202e
Archive: https://codeload.github.com/zlib-ng/zlib-ng/tar.gz/49323f2af98b92fccf03cfc62ea2cb5591a3202e
SHA-256: bc36e6f11cdbe71352b551ed98c94cd9d5f13dc248f3c3b56c518cc72678d604

1) For the maintained pin, verify the archive checksum and run from the JDK root:
   python3 make/scripts/update-zlib-ng.py --archive /path/to/zlib-ng-COMMIT.tar.gz \
       --revision COMMIT --sha256 VERIFIED_SHA256
   A new revision requires a deliberate patch rebase and importer checksum update
   following make/data/zlib-ng/README.md; drift fails before checkout writes.
   The importer reapplies the maintained implementation and synthetic probe,
   preserves the upstream license and regenerates the attributed JDK legal notice.
   Run make test-make-zlib-ng-import for offline failure/replay checks and repeat
   regeneration with the official pinned archive to verify exact provenance.

2) Keep zlib-ng/LICENSE.md and src/java.base/share/legal/zlib-ng.md.
   Keep this file outside zlib-ng/: the importer replaces that directory.

3) Build through make/common/Zlib.gmk with the configured target compiler/sysroot.
   Linux/macOS/Windows x86-64/AArch64 use native mode and jdk_ng_native_ names.
   Preserve stock fallback and build-host selection. Windows requires CMake/NMake
   with configured MSVC. --with-zlib selections are rejected.

4) Keep the libzip/libjli adapters and generated native headers consistent.
   Static packaging includes one libzlibng archive; consumers retain references.
   Preserve JNI, ZIP_* interfaces, checksums, allocator hooks and the level-1
   mapping to ng level 2 and Java stream/GC/error accounting. Test ZIP/checksums
   and stock fallback using test/hotspot/jtreg/compiler/intrinsics/zip/ and
   test/jdk/java/util/zip/.
